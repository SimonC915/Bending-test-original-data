# Bending-test-original-data
The data contained in this database are load-displacement data from three-point bending tests of 3D printed continuous hybrid fiber-reinforced composites.

# Conditions
The three-point bending test were performed using a 200 kN standard universal testing machine (SANS-CMT5205). A standard bending fixture was used, which consisted of two supports and an indenter, each with a diameter of 30 mm and a span of 120 mm. The loading speed was set to 4 mm/min and the total loading displacement was 35 mm.
